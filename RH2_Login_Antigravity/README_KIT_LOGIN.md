# RH2.0 — Kit de Login para Antigravity

## Conteúdo
- `docs/authentication/SPEC.md`: especificação adaptada de login/autenticação para RH2.0.
- `docs/authentication/PROMPT_PLANNING.md`: prompt para Planning Mode, sem implementar.
- `docs/authentication/CRITERIOS_DE_ACEITE.md`: checklist de aceite.
- `material_de_apoio/`: arquivos originais do kit do professor, preservados.

## Como usar
1. Extraia este ZIP na raiz do workspace RH2.0 (ou copie as pastas mantendo os caminhos).
2. Abra o workspace no Antigravity.
3. Execute o conteúdo de `docs/authentication/PROMPT_PLANNING.md` no Planning Mode.
4. Revise o plano e as decisões pendentes.
5. Só depois de aprovar, solicite implementação por etapas.

## Atenção
A SPEC é uma proposta de adaptação, não uma decisão final de arquitetura. A stack oficial do RH2.0 e os documentos dos gestores prevalecem. Não implemente SQLite/Express ou autenticação paralela apenas por constarem no kit didático.
