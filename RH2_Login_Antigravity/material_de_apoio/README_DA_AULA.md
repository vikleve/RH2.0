# Oficina — Spec-Driven Development de uma tela de login usando Antigravity

**Produto:** FolhaFácil Demo, um login genérico que representa a entrada de um sistema de folha de pagamento, **sem dados salariais reais**.

**Resultado esperado:** aplicação local em Node.js + React/TypeScript + Express/TypeScript, SQLite, login, sessão, rota protegida, logout, testes e evidências AC-01..AC-16.

## Arquivos deste pacote
- `SPEC.md`: especificação única do projeto.
- `CRITERIOS_DE_ACEITE.md`: testes verificáveis por ID.
- `AGENTS.md`: regras para agente e limites de escopo.
- `PROMPTS_ANTIGRAVITY.md`: uma solicitação para planejamento + continuação por aprovação; uma correção consolidada opcional.
- `ROTEIRO_TESTE_MANUAL.md`: observações de navegador e comandos após gerar o projeto.

## Fluxo de aula sugerido
1. **Entender a demanda** (10 min): por que login não é só CSS e HTML?
2. **Ler a spec e os aceites** (15 min): duplas devem identificar lacunas e explicar G0.
3. **Preparar o workspace** (10 min): copiar os três arquivos e verificar Node/Git.
4. **Chamada única de planejamento** (5–15 min de sala, sem promessa de duração de execução): copiar o prompt `/plan` e avaliar o artefato.
5. **Aprovar e acompanhar execução**: clicar Proceed; observar alterações e comandos reais.
6. **Testar manualmente** (15 min): roteiro e matriz AC, executar verificações no terminal.
7. **Correção apenas se houver falhas**: agrupar logs em uma mensagem; executar Prompt 2.
8. **Apresentar evidências**: cada dupla explica dois critérios de aceite e as provas.

## Observação importante
Aulas e créditos variam. O número de prompts **não determina** um volume fixo de créditos. O objetivo é diminuir solicitações redundantes e retrabalho, não prometer um limite de consumo.
